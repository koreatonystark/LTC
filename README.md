# 안성 장기요양 가이드 2026

경기도 안성시 장기요양 완전 지원 가이드 — 모바일 웹앱

## 사용 방법

1. GitHub Pages 활성화: Settings → Pages → Branch: main → Save
2. URL: `https://[username].github.io/[repo-name]/anseong_v4-mobile-final-v8.html`

## 파일 구성

| 파일 | 설명 |
|------|------|
| `anseong_v4-mobile-final-v8.html` | 메인 앱 |
| `manifest.json` | PWA 설정 |
| `sw.js` | 오프라인 캐시 |
| `icon-192.png` / `icon-512.png` | 홈화면 아이콘 (별도 추가 권장) |

## 홈화면 추가

- **Android**: 브라우저 메뉴 → "홈 화면에 추가"
- **iPhone**: Safari 공유버튼 → "홈 화면에 추가"
